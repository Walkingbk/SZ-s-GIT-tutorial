    # SZ's GIT Tutorial

A Git tutorial repository.


Terminologies:

.gitignore: A plain text file that tells Git which files or directories to ignore in a project
    Privacy: Help hide important local information when project is uploaded into github

commit: The action of submitting one version of a code onto github. 
    Whenever you commit a file/code, git creates a snapshot of the repository in a "main" branch. 
    This forms a historic, retraceable chain of past versions

Commit id: A string of number and text, generated by the Hash algorithm of Git, to bookeep/reference different past version of the file
    Commit id (or commit hash) can be long or short, both of them work the same 
    Commit id can be used in coding agent like Claude to reference, alter, or restore past versions 

checkout (Detached): A functionality within the source control panel of VScode that allows you to view a past version of the code. 
    Not suited for creating new branch, but simply serve inspection purposes





Takeaways:

Commit can be a powerful tool to track changes in code during vibe coding. Whenever coding agents, like Claude Code, created a new functionality, we could commit a newer version.
This streamline bookeeping of historic versions, and restore retraceability of the codes
